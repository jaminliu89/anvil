# Anvil · PRD

> 本地 AI 工作站 · 用户唯一入口 · 零术语

## 产品定义

Anvil 是一台「本地 AI 工作站」：用户打开它就能对话、调性能、训模型、接 Agent。
所有专业能力（推理引擎、协议守卫、训练管线、Agent 桥接）藏在背后，用户只见结果。

**一句话**：普通用户获得本地 AI 的全部能力，一行命令都不用敲。

## 终局架构（v2 定版，2026-08-16）

```
┌─ Anvil（唯一入口，零术语）──────────────────────┐
│ 普通模式：对话 · 运行 · 设置                     │
│ 高级模式：+ 训练 · 连接 · 守卫面板               │
│                                                 │
│ Python sidecar（DSH 守卫：协议加固）            │
└──────┬───────────────────────────────────┬─────┘
       ▼                                   ▼
  推理路由器（可切换）                 Unsloth :8888
  ├ Ling-tiny :18080（主力）           训练/导出/跑模型
  └ Unsloth :8888（训练产物直接跑）
```

### 三条铁律

1. **推理路由器**——「大脑」只有一个概念，背后端点可切（:18080 / :8888），切换用户无感。
2. **训练全走 Unsloth API**——Anvil 训练页是 Unsloth 的零术语皮肤，不自研训练。
3. **Agent 桥接全走 unsloth start**——已支持 claude/codex/hermes/pi/openclaw/opencode，Anvil 只做按钮。

### 零术语铁律（UI 禁用词表）

禁：llama-server / ngl / ctx_size / GGUF / endpoint / sidecar / harness / token / API key / OpenAI 兼容
替：「大脑」「速度」「记忆长度」「模型文件」「接口」「守卫」「钥匙」

## 模式定义

| | 普通模式 | 高级模式 |
|---|---|---|
| 导航 | 对话 · 运行 · 设置 | + 训练 · 连接 · 守卫 |
| 对话 | 守卫静默生效 | 守卫可视化（体检/预估/审计） |
| 目标用户 | 自己用 | 折腾的人 |
| 切换 | 设置页底部开关，侧边栏底部入口 | 同左 |

## 页面规格

### 对话（默认首页）
- 消息流（markdown 渲染、代码高亮）
- 思考过程折叠条（守卫分离出的 reasoning）
- 发送前预估提示（token → 「预计消耗」）
- 守卫状态角标（静默抢救计数）

### 运行
- 大脑状态卡（哪个模型、速度、记忆占用）
- 启动/停止/重启
- 性能滑块（温度→「发散度」、ctx→「记忆长度」）
- 「体检」按钮（= dsh doctor 可视化）

### 训练（高级）
- 选基座模型（Unsloth 模型库搜索）
- 拖入数据（文件夹/.md）
- 训练进度（loss 曲线）
- 导出 & 一键换脑（产物直接进推理路由器）

### 连接（高级）
- Agent 卡片：Claude Code / Codex / Hermes / Pi
- 每张卡：检测已装 → 一键桥接（unsloth start <agent>）

### 守卫面板（高级）
- 体检（doctor）
- 消息审计（validate，拖 messages.json）
- 自检（probe）
- 抢救日志（tool_calls salvage 历史）

### 设置
- 主题（暖/暗）
- 开机自启
- 模式切换（普通/高级）
- 关于（版本）
