What & Why

Forge 是什么

一套整合式开源方案，把 M 芯片 Mac 变成本地 AI 开发工作站。跑推理、接 Agent、离线可用、零 API 费用。

对比 Ollama、LM Studio、GPT4All 等竞品，Forge 的核心差异不是又多一个模型管理器——而是面向 Agent 开发场景做端到端集成：全 GPU 加速推理 + 64K 上下文 + Claude Code/Codex 桥接 + Hermes fallback 链路，开箱即用。

Architecture

系统架构

应用层
dsh-gui (Tauri) — 桌面管理面板
服务层
DeepSeek Harness (:3080) / llama-server (:18080) / Unsloth Desktop (:11434)
Agent 层
Claude Code / Codex CLI / Hermes Agent 直连或桥接
推理层
Ling-3.0-tiny (bailingmoe3) / llama.cpp · 全 GPU 加速 · 64K ctx

四层架构，每层可独立替换。
推理走本地 Ling → 云端 DeepSeek fallback；Agent 直连推理端点，不经过中间层。

Quick Start

三分钟起步

# A档：终端里直接跑推理
curl :18080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"ling","messages":[{"role":"user","content":"hello"}]}'

# B档：装 Hermes fallback（自动切换）
hermes config set fallback.url http://127.0.0.1:18080/v1
hermes config set fallback.model ling

# C档：装 Unsloth + dsh-gui
brew install unsloth  # 或 pip install unsloth
cd dsh-gui && cargo tauri dev

Brand

名字怎么来的

Forge — 锻造。这个名字来自一个意象：本地 Mac 像一个锻造炉，开发者把数据、模型、代码放进去，锻造成成品。

不是"又一个模型管理器"，而是"你的本地 AI 锻造车间"。不依赖云端，不产生 API 费用，所有锻造过程都在本机完成。
